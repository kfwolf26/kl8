# 福彩快乐8过滤工具（狼奖多多）

一款基于 Python + Tkinter 开发的福彩快乐8辅助工具，集成了选十过滤、历史查询、走势图、预测模型和定位定胆等多种功能，帮助彩民进行号码分析与筛选。

## 功能特点

本工具采用多标签页界面设计，主要包含以下五大模块：

### 🎯 过滤工具
对快乐8选十（1-80 中选 10 个号码）进行多条件组合过滤：
- **杀号**：手动剔除不想要的号码
- **奇偶比**：限定 10 个号码中奇数与偶数的比例（10:0 ~ 0:10）
- **大小比**：限定小数（1-40）与大数（41-80）的比例
- **四区分布**：1区(1-20)、2区(21-40)、3区(41-60)、4区(61-80) 各区出现次数
- **和值范围**：号码之和的区间限定（55 ~ 755）
- **跨度范围**：最大号码与最小号码之差（9 ~ 79）
- **连号类型**：无连号 / 2连 / 3连 / 4连 / 5连+

> 当全组合数 ≤ 500 万时穷举所有组合；超过时自动切换为 50 万注随机采样，结果显示上限 5000 注。

### 📊 历史查询
管理快乐8历史开奖数据，支持：
- 单期添加 / 删除记录
- 批量导入历史数据
- 按期号查询开奖结果
- 自动计算每期属性（和值、跨度、奇偶比、大小比、四区分布、连号类型）
- 清空全部历史数据

历史数据保存在 `history.json` 中。

### 📈 走势图
一键打开外部走势图网页：
- 中彩网快乐8走势图
- 500彩票网走势图
- 福彩官网开奖页面

### 🔮 预测模型
基于历史开奖数据进行下期号码预测：
- 多个虚拟"预测者"分别给出选号
- 按预测者频率统计生成选十推荐码
- 选十奖级表参考（一等奖 500 万 ~ 安慰奖 2 元）
- 支持预测数据保存与加载

预测数据保存在 `prediction_data.json` 与 `saved_predictions.json` 中。

### 🎯 定位定胆
针对定位玩法的统计分析工具，包含四个子标签页：
- **定三胆**：选出 3 个高概率命中开奖号的号码
- **定五胆**：选出 5 个高概率命中开奖号的号码
- **杀三码**：选出 3 个高概率不在开奖号中的号码
- **杀五码**：选出 5 个高概率不在开奖号中的号码

支持自定义统计期数，通过 10 位虚拟预测者（神算子、好运来、金手指等）进行综合分析。

## 项目结构

```
kl8/
├── main.py                     # 程序入口，主窗口与标签页装配
├── history.json                # 历史开奖数据存储
├── prediction_data.json        # 预测数据存储
├── saved_predictions.json      # 已保存的预测记录
├── prediction_settings.json    # 预测模型配置
├── modules/                    # 功能模块
│   ├── filter_tool.py          # 过滤工具
│   ├── history_query.py        # 历史查询
│   ├── trend_chart.py          # 走势图
│   ├── prediction_model.py     # 预测模型
│   └── location_dingdan.py     # 定位定胆
└── utils/
    └── history_manager.py      # 历史数据管理（单例）
```

## 环境依赖

- Python 3.10+
- 仅使用 Python 标准库（tkinter、json、os、random、itertools、math、threading、webbrowser 等），**无需安装第三方依赖**

> Windows 系统通常已自带 tkinter；如 Linux 系统提示缺失，请执行 `sudo apt-get install python3-tk`。

## 快速开始

1. 克隆仓库：
   ```bash
   git clone https://github.com/你的用户名/kl8.git
   cd kl8
   ```

2. 运行主程序：
   ```bash
   python main.py
   ```

3. 在「历史查询」标签页中导入或手动添加开奖历史后，即可使用过滤、预测、定胆等功能。

## 使用说明

1. **录入历史数据**：先在「历史查询」中添加历期开奖号码（格式：`n1,n2,...,n20`，共 20 个号码）。
2. **设置过滤条件**：在「过滤工具」中勾选/填写需要的过滤条件，点击「开始过滤」查看结果。
3. **生成预测**：在「预测模型」中基于历史数据生成下期推荐号码。
4. **定胆分析**：在「定位定胆」中选择统计期数，查看各位预测者的定胆/杀码表现。

## 数据文件说明

| 文件 | 说明 |
| --- | --- |
| `history.json` | 存储所有历史开奖记录，按期号倒序排列 |
| `prediction_data.json` | 存储预测模型生成的预测数据 |
| `saved_predictions.json` | 存储已保存的预测结果，便于回溯比对 |
| `prediction_settings.json` | 存储预测模型的相关配置参数 |
